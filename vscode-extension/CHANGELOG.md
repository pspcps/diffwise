# Changelog

## 0.1.0

- Bundle all 20 PSDevTool tools into a single VS Code webview.
- Add a native categorized tool sidebar and quick picker.
- Bundle Monaco editor and language workers for local loading.
- Connect copy/paste and file export to VS Code clipboard and Save dialogs.
- Add explicit import of selected editor text without replacing existing inputs automatically.
- Support nested resume routes, local resume profiles, inline QR codes and printable HTML export.
- Exclude website analytics and advertising from the extension entry.
